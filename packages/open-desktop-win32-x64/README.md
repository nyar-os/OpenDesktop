# `@wae/open-desktop-win32-x64`

Native Node-API addon for `@wae/open-desktop` on `win32-x64`.

The package ships one file, `open-desktop.win32-x64.node`, built from the
`open-desktop-napi` crate. It is installed by the meta package as an optional
dependency and is never loaded on other platforms.
